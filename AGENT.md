# AtmosphericClouds — agent guide

## Research

For cloud/atmosphere design, implementation order, and technical decisions:

1. **Use only** [`Docs/REFERENCE.md`](Docs/REFERENCE.md) as the documentation index.
2. **Fetch and read** the papers, articles, and repos listed there before answering or coding.
3. **Ignore** other files in `Docs/` (`STEPS.md`, `PROGRESSION.md`, `NOTES.md`, etc.) — do not use them for research or planning.

If `REFERENCE.md` is updated, follow the new links on the next task.
